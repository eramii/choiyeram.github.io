SCMC — 메타인지 기반 선택적 자기수정 프레임워크

2026.01 – 2026.03

팀장 · 2인 연구 · 기여도 50% — 프레임워크 제안 및 실험 주도 (ETRI 제주AX융합연구실)

KCC 2026 포스터 발표 · 제1저자 정확도 56.68% → 60.60% (+3.92%p) 평균 호출 2.53회 (기존 5~6회)

Problem

소형 언어모델(Qwen2.5-3B-Instruct)이 유사한 질문에서 맥락을 혼동해 잘못된 도구(API)를 선택하는 문제. 예: “주유소 제일 저렴한 곳 알려줘” → 정답은 가격 API인데 위치 API를 제시. 기존 자기수정 기법을 일괄 적용하면 정답까지 오답으로 고치는 overcorrection으로 오히려 성능이 하락.

Approach

  1. 도구 혼동이 잦은 질문을 모아 선택 과정을 역추적 — 질문은 서술형 자연어, 도구 설명은 기능 명칭형이라 임베딩 공간에서 의미가 어긋나 retrieval 단계에서 정답이 후보군에 진입하지 못하는 구조적 불일치를 확인
  2. 쿼리–도구 코사인 유사도, 토큰 엔트로피, 검색 마진, 첫 토큰 확률을 가중 결합한 메타인지 점수 설계
  3. 신뢰도가 낮을 때만 재검색·재생성하는 SKIP / LIGHT / FULL 3단계 선택적 수정 구조로 구현

Result

MetaTool 벤치마크 도구 선택 정확도 56.68% → 60.60% (+3.92%p). 일괄 수정(Always LIGHT/FULL)은 baseline보다 하락한 반면, 선택적 수정은 평균 2.53회 호출로 더 적은 비용으로 더 높은 정확도를 달성. 오답 비용이 큰 현장 LLM의 신뢰성 조건을 실험으로 검증.

악천후 환경 경량 객체탐지

2025.03 – 2025.12

팀장 · 2인 개발 · 기여도 60% — EfficientNet 변경 프레임워크 설계 및 비교 실험 (캡스톤디자인 2)

적정기술학회지 게재 · 제1저자 mAP50 79.22% (+7.83%p) 추론 속도 23% 향상 실제 CCTV mAP50-95 57.9%

Problem

장마철 안개로 인한 교통사고가 빈번한 제주에서, CCTV 같은 저사양 하드웨어로도 동작하는 악천후 객체탐지 모델이 필요했습니다. 제약된 연산 환경에서의 탐지 문제.

Approach

  1. 참고 논문(Swin 백본)의 공개 코드 부재 → 직접 구현으로 재현, Swin 계열의 높은 연산량은 CCTV 환경에 부적합 판단
  2. 백본을 EfficientNet으로 교체하고 파라미터·추론시간·정확도를 반복 측정, YOLO Head P3·P4·P5에 EMA(Efficient Multi-scale Attention) 결합으로 흐릿한 객체 경계 보강
  3. 실제 CCTV 투입 시 정확도 하락 → 공개 데이터는 정면 화각, CCTV는 부감 화각이라는 분포 차이로 진단
  4. 장마철 안개 환경 데이터를 직접 수집·라벨링해 학습 데이터를 재구성하고 YOLO 버전 확장

Result

mAP50 79.22%(기준 모델 대비 +7.83%p), Swin 백본 대비 추론 속도 23% 향상, 파라미터 4~5M의 경량 구조 유지. 벤치마크가 아닌 제주교통정보센터 실제 CCTV로 검증해 이질적인 현장 데이터에서의 일반화를 확인 — “현장에서 되는가”에 답한 경험.

Multi-LLMSeg — 멀티모달 LMM 복수 객체 세그멘테이션

2025.03 – 2025.09

팀원 · 3인 개발 · 기여도 50% — Slot 병렬 디코딩 구조 설계 (최신 연구·논문 트렌드 탐구 전공 프로젝트)

단일 객체 → 복수 객체 동시 분할로 구조 확장 gIoU 41.9% · cIoU 18.8%

Problem

LLM 기반 이미지 분할 모델 LISA는 한 번에 1개 객체만 분할 가능 — “빨간 선박과 파란 자동차를 분할해줘” 같은 요청은 순차 처리만 가능하고 동시 분할이 불가능한 구조적 한계.

Approach

  1. 텍스트 입력 → LLaVA가 객체 수를 파악해 [SEP]·[SEG] 토큰으로 N개 슬롯 생성
  2. SAM ViT 인코더의 이미지 특징 위에서 각 슬롯이 자기 객체 영역에 어텐션 집중, 슬롯 간 경쟁으로 중복 할당 방지
  3. 초기 마스크가 무작위로 할당되는 현상을 토큰 간 표현 학습 부족으로 진단 후 Slot Attention으로 안정화
  4. SAM-style 병렬 디코더로 객체별 마스크 동시 출력, A100 ×7 분산 처리로 10 epochs 학습 (데이터셋 직접 구축)

Result

단일 객체 처리에서 복수 객체 동시 분할로 구조적 확장 (gIoU 41.9%, cIoU 18.8%). 자연어 지시로 다중 객체를 분할하는 구조는 라벨 없는 신규 대상에도 언어로 대응하는 차세대 Vision 검사로 이어지는 접근입니다.
